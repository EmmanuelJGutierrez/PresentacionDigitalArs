## 🚀 Cómo visualizar la presentación

1. Descargá o cloná este repositorio:
   ```bash
   git clone https://github.com/EmmanuelJGutierrez/PresentacionDigitalArs.git
   ```
2. Hacé **doble clic en `index.html`** para abrirlo en tu navegador favorito (Google Chrome, Edge, Brave, Firefox).
3. **No requiere instalación ni dependencias.** Funciona de forma 100% nativa y offline.

## ⌨️ Atajos del Expositor en Vivo

| Tecla / Acción | Función |
| :--- | :--- |
| **`→` / `Espacio`** | Avanzar a la siguiente diapositiva |
| **`←` / `Backspace`** | Retroceder a la diapositiva anterior |
| **`1` al `5`** | Saltar directamente a una diapositiva específica |
| **`F` / `F11`** | Activar / Desactivar **Pantalla Completa 16:9** |
| **`N`** | Abrir panel inferior de **Notas del Orador** (guion sugerido) |
| **`T`** | Iniciar / Pausar el **Cronómetro de 5 minutos** |
| **`🌓` (Botón)** | Alternar entre **Modo Oscuro** y **Modo Claro** |
| **`Ctrl + P`** | Imprimir / Guardar como PDF apaisado |

## 📋 Estructura de la Presentación (Regla de 5 Minutos)

1. **Diapositiva 1 · Presentación del Equipo (30 - 45s):** Quiénes somos, perfiles por track y metodología ágil de trabajo sincronizado.
2. **Diapositiva 2 · El Problema (45 - 60s):** Brecha de accesibilidad universal (lectores de pantalla ignorados), inconsistencia multi-dispositivo (mobile vs. desktop) y opacidad financiera.
3. **Diapositiva 3 · La Solución — DigitalArs (90s):** Maqueta interactiva real de la plataforma con Dashboard, transferencias con validación en vivo de Alias/CVU, simulador de plazos fijos y tarjetas virtuales.
4. **Diapositiva 4 · Propuesta de Valor (60s):** Accesibilidad universal nativa WCAG 2.1 AA (sincronización de lang para TalkBack/VoiceOver), micro-animaciones fluidas y transacciones bancarias atómicas con doble asiento contable.
5. **Diapositiva 5 · Llamado a la Acción y Cierre (30s):** Roadmap futuro (pagos QR y microcréditos), frase de cierre inspiradora y conclusión del equipo.
